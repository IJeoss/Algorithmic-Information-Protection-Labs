# Лабораторная работа №1 — умножение многочленов

Курс: **Алгоритмические аспекты защиты информации**

Вариант 2.

## Задание

Реализовать алгоритмы умножения многочленов над `R`:

- алгоритм Карацубы;
- алгоритм Тоома — Кука при `k = 3`.

Проверить корректность вычислений на многочленах малых степеней.

Провести измерение времени выполнения алгоритмов для случайных многочленов степени

`2^n`, где `n ∈ {5, 10, 15, 18}`.

Для построения графика дополнительно проводятся измерения для всех `n` от 5 до 18.

## Представление многочлена

Многочлен хранится в виде слайса коэффициентов:

```go
type Polynomial []float64
```

Элемент с индексом `i` является коэффициентом при `x^i`.

Например:

```go
Polynomial{1, 2, 3}
```

соответствует многочлену

```text
1 + 2x + 3x²
```

Коэффициенты имеют тип `float64`, так как по условию рассматриваются многочлены над `R`.

Для работы с многочленами реализованы вспомогательные операции:

- сложение;
- вычитание;
- умножение на константу.

## Реализованные алгоритмы

### Обычное умножение

Дополнительно реализован классический алгоритм умножения многочленов со сложностью

```text
O(n²)
```

для многочленов сопоставимых степеней.

Он используется:

- для проверки корректности рекурсивных алгоритмов;
- как базовый случай Карацубы и Тоома — Кука на небольших многочленах.

Порог перехода к обычному умножению:

```go
const naiveThreshold = 32
```

### Алгоритм Карацубы

Многочлены разбиваются на две части:

```text
A(x) = A0(x) + x^m A1(x)
B(x) = B0(x) + x^m B1(x)
```

Вместо четырёх обычных произведений выполняются три рекурсивных:

```text
z0 = A0 * B0
z2 = A1 * B1
z1 = (A0 + A1)(B0 + B1) - z0 - z2
```

После этого результат собирается как

```text
A(x)B(x) = z0 + x^m z1 + x^(2m) z2
```

Асимптотическая сложность:

```text
O(n^log₂3) ≈ O(n^1.585)
```

### Алгоритм Тоома — Кука при `k = 3`

Каждый многочлен разбивается на три блока:

```text
A(x) = A0(x) + x^m A1(x) + x^(2m) A2(x)
B(x) = B0(x) + x^m B1(x) + x^(2m) B2(x)
```

Для уменьшения количества рекурсивных умножений значения блоковых многочленов вычисляются в пяти точках:

```text
0, 1, -1, 2, ∞
```

Для каждой точки выполняется рекурсивное умножение.

После этого с помощью интерполяции восстанавливаются блоки результата:

```text
C0, C1, C2, C3, C4
```

Итоговый многочлен собирается в виде:

```text
C(x) =
    C0 +
    x^m C1 +
    x^(2m) C2 +
    x^(3m) C3 +
    x^(4m) C4
```

Асимптотическая сложность:

```text
O(n^log₃5) ≈ O(n^1.465)
```

## Структура проекта

```text
.
├── main.go
├── polynomial.go
├── naive.go
├── karatsuba.go
├── toom3.go
├── random.go
├── benchmark.go
├── algorithms_test.go
└── plot_results.py
```

### `polynomial.go`

Содержит:

- тип `Polynomial`;
- `add` — сложение двух многочленов;
- `sub` — вычитание многочленов;
- `constMul` — умножение многочлена на число;
- `naiveThreshold` — порог перехода к обычному умножению.

### `naive.go`

Содержит функцию `naiveMul`, реализующую обычное умножение многочленов за `O(n²)`.

Используется как базовый алгоритм и как эталон при тестировании рекурсивных алгоритмов.

### `karatsuba.go`

Содержит реализацию функции `karatsuba`.

Многочлены рекурсивно делятся на две части, после чего выполняются три рекурсивных умножения вместо четырёх.

### `toom3.go`

Содержит:

- `split3` — разбиение многочлена на три блока;
- `toom3` — реализацию алгоритма Тоома — Кука при `k = 3`.

Алгоритм состоит из следующих этапов:

1. разбиение многочленов на три части;
2. вычисление значений в точках `0`, `1`, `-1`, `2`, `∞`;
3. пять рекурсивных умножений;
4. интерполяция;
5. сборка итогового многочлена.

### `random.go`

Содержит функцию `randomPolynomial`, создающую случайный многочлен заданной степени.

Коэффициенты генерируются как вещественные числа из диапазона

```text
[-10; 10)
```

Генератор случайных чисел передаётся функции извне.

### `benchmark.go`

Содержит функцию `measureAlgorithm` для измерения времени выполнения алгоритма.

Время измеряется средствами пакета `time`.

Переменная `benchmarkSink` сохраняет часть результата вычисления, чтобы результат выполнения алгоритма не оставался полностью неиспользуемым.

### `algorithms_test.go`

Содержит тесты корректности для:

- обычного умножения;
- Карацубы;
- Тоома — Кука.

Проверяются:

- константы;
- линейные многочлены;
- многочлены разных степеней;
- отрицательные коэффициенты;
- дробные коэффициенты;
- нулевой многочлен;
- разреженные многочлены.

Для сравнения вещественных коэффициентов используется погрешность:

```go
const eps = 1e-9
```

Также отдельно проверяется рекурсивная работа Карацубы и Тоома — Кука на многочленах большего размера. В качестве эталона используется обычное умножение.

### `main.go`

Основная программа для проведения эксперимента.

Для каждого

```text
n = 5, 6, ..., 18
```

создаются два случайных многочлена степени

```text
2^n
```

и измеряется время выполнения:

- алгоритма Карацубы;
- алгоритма Тоома — Кука.

Используется генератор псевдослучайных чисел с фиксированным `seed`:

```go
rand.NewSource(67)
```

Это позволяет при повторных запусках получать одинаковую последовательность случайных коэффициентов.

Результаты выводятся в терминал и сохраняются в файл:

```text
results.csv
```

Формат CSV:

```text
n,degree,karatsuba_ms,toom3_ms
```

### `plot_results.py`

Python-скрипт для визуализации результатов эксперимента.

Скрипт читает `results.csv` и строит два графика.

Первый показывает измеренное время работы:

- алгоритма Карацубы;
- алгоритма Тоома — Кука.

График сохраняется в:

```text
results_plot.png
```

Второй показывает теоретический рост сложности:

```text
Обычный алгоритм: O(n²)
Карацуба:         O(n^log₂3)
Тоом — Кук-3:     O(n^log₃5)
```

График сохраняется в:

```text
complexity_plot.png
```

## Запуск

### Требования

Для основной части лабораторной работы необходим Go.

Для построения графиков дополнительно необходимы:

- Python 3;
- `matplotlib`.

Установить `matplotlib` можно командой:

```bash
python3 -m pip install matplotlib
```

## Проверка корректности

Запуск всех тестов:

```bash
go test ./...
```

Запуск с подробным выводом:

```bash
go test -v ./...
```

## Проверка покрытия тестами

Для получения общего процента покрытия:

```bash
go test ./... -cover
```

Для создания файла с профилем покрытия:

```bash
go test ./... -coverprofile=coverage.out
```

После этого подробную статистику по функциям можно посмотреть командой:

```bash
go tool cover -func=coverage.out
```

HTML-отчёт с подсветкой покрытых и непокрытых участков кода:

```bash
go tool cover -html=coverage.out
```

На macOS отчёт обычно открывается в браузере автоматически.

### Просмотр покрытия в VS Code

Если установлено официальное расширение **Go** для VS Code, профиль `coverage.out` можно применить прямо в редакторе.

1. Сгенерировать профиль:

```bash
go test ./... -coverprofile=coverage.out
```

2. Открыть палитру команд:

```text
Cmd + Shift + P
```

3. Выбрать:

```text
Go: Apply Cover Profile
```

4. Указать файл:

```text
coverage.out
```

Также можно использовать команду:

```text
Go: Toggle Test Coverage In Current Package
```

Она запускает тесты для текущего пакета и отображает покрытие непосредственно в редакторе.

> Расширение Coverage Gutters не читает стандартный Go-профиль `coverage.out` напрямую, поэтому для Go удобнее использовать встроенную поддержку покрытия в официальном расширении Go.

Файл `coverage.out` является генерируемым и его рекомендуется добавить в `.gitignore`:

```gitignore
coverage.out
```


```bash
go run main.go polynomial.go naive.go karatsuba.go toom3.go random.go benchmark.go
```

В терминале появятся строки вида:

```text

n=6 degree=64 karatsuba=...ms toom3=...ms
...
n=18 degree=262144 karatsuba=...ms toom3=...ms
```

Одновременно будет создан файл:

```text
results.csv
```
