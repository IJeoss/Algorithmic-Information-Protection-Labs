## Задание

Реализовать алгоритмы умножения многочленов над `R`:

- алгоритм Карацубы;
- алгоритм Тоома — Кука при `k = 3`.

Проверить корректность вычислений на многочленах малых степеней.

Провести измерение времени выполнения алгоритмов для случайных многочленов степени

`2^n`, где `n ∈ {5, 10, 15, 18}`.

Для построения графика дополнительно проводятся измерения для всех `n` от 5 до 18.

## Представление многочлена

Многочлен хранится в виде слайса коэффициентов:

```go
type Polynomial []float64
```

Элемент с индексом `i` является коэффициентом при `x^i`.

Например:

```go
Polynomial{1, 2, 3}
```

соответствует многочлену

```text
1 + 2x + 3x²
```

Для работы с многочленами реализованы вспомогательные операции сложения, вычитания и умножения на константу.

Коэффициенты имеют тип `float64`, так как по условию рассматриваются многочлены над `R`.

## Реализованные алгоритмы

### Обычное умножение

Дополнительно реализован классический алгоритм умножения многочленов со сложностью

```text
O(n²)
```

для многочленов сопоставимых степеней.

Он используется:

- для проверки корректности рекурсивных алгоритмов;
- как базовый случай Карацубы и Тоома — Кука для небольших многочленов.

Порог перехода к обычному умножению:

```go
const naiveThreshold = 32
```

### Алгоритм Карацубы

Многочлены разбиваются на две части:

```text
A(x) = A0(x) + x^m A1(x)
B(x) = B0(x) + x^m B1(x)
```

Вместо четырёх обычных произведений выполняются три рекурсивных:

```text
z0 = A0 * B0
z2 = A1 * B1
z1 = (A0 + A1)(B0 + B1) - z0 - z2
```

После этого результат собирается как

```text
A(x)B(x) = z0 + x^m z1 + x^(2m) z2
```

Асимптотическая сложность алгоритма:

```text
O(n^log₂3) ≈ O(n^1.585)
```

### Алгоритм Тоома — Кука при k = 3

Каждый многочлен разбивается на три блока:

```text
A(x) = A0(x) + x^m A1(x) + x^(2m) A2(x)
B(x) = B0(x) + x^m B1(x) + x^(2m) B2(x)
```

Для уменьшения количества рекурсивных умножений значения блоковых многочленов вычисляются в пяти точках:

```text
0, 1, -1, 2, ∞
```

Для каждой точки выполняется рекурсивное умножение полученных значений.

Затем с помощью интерполяции восстанавливаются блоки результата:

```text
C0, C1, C2, C3, C4
```

и итоговый многочлен собирается в виде

```text
C(x) =
    C0 +
    x^m C1 +
    x^(2m) C2 +
    x^(3m) C3 +
    x^(4m) C4
```

Асимптотическая сложность:

```text
O(n^log₃5) ≈ O(n^1.465)
```

## Структура проекта

```text
.
```

### `polynomial.go`

Содержит базовое представление многочлена:

```go
type Polynomial []float64
```

а также вспомогательные операции:

- `add` — сложение двух многочленов;
- `sub` — вычитание многочленов;
- `constMul` — умножение многочлена на число.

Также здесь задаётся `naiveThreshold` — размер, при котором рекурсивные алгоритмы переходят к обычному умножению.

### `naive.go`

Содержит функцию

```go
naiveMul
```

реализующую обычное умножение многочленов за `O(n²)`.

Используется как базовый алгоритм и как эталон при тестировании рекурсивных алгоритмов.

### `karatsuba.go`

Содержит реализацию

```go
karatsuba
```

алгоритма Карацубы.

Многочлены рекурсивно делятся на две части, после чего выполняются три рекурсивных умножения вместо четырёх.

### `toom3.go`

Содержит:

```go
split3
toom3
```

`split3` разбивает многочлен на три блока.

`toom3` реализует алгоритм Тоома — Кука при `k = 3`:

1. разбиение многочленов на три части;
2. вычисление значений в точках `0`, `1`, `-1`, `2`, `∞`;
3. пять рекурсивных умножений;
4. интерполяцию полученных результатов;
5. сборку итогового многочлена.

### `random.go`

Содержит функцию

```go
randomPolynomial
```

создающую случайный многочлен заданной степени.

Коэффициенты генерируются как вещественные числа из диапазона

```text
[-10; 10)
```

Генератор случайных чисел передаётся функции извне.

### `benchmark.go`

Содержит функцию

```go
measureAlgorithm
```

для измерения времени выполнения алгоритма.

Время измеряется средствами пакета `time`.

Дополнительная переменная `benchmarkSink` сохраняет часть результата вычисления, чтобы результат выполнения алгоритма не оставался полностью неиспользуемым.

### `algorithms_test.go`

Содержит тесты корректности реализаций.

На небольших заранее заданных многочленах проверяются:

- обычное умножение;
- Карацуба;
- Тоом — Кук.

Тестируются, в частности:

- константы;
- линейные многочлены;
- многочлены разных степеней;
- отрицательные коэффициенты;
- дробные коэффициенты;
- нулевой многочлен;
- разреженные многочлены.

Для сравнения результатов используется погрешность

```go
const eps = 1e-9
```

Также отдельно проверяется рекурсивная работа Карацубы и Тоома — Кука на многочленах большего размера. В качестве эталонного результата используется обычное умножение.

### `main.go`

Основная программа для проведения эксперимента.

Для каждого

```text
n = 5, 6, ..., 18
```

создаются два случайных многочлена степени

```text
2^n
```

и измеряется время выполнения:

- алгоритма Карацубы;
- алгоритма Тоома — Кука.

Используется генератор псевдослучайных чисел с фиксированным `seed`:

```go
rand.NewSource(67)
```

Это позволяет при повторных запусках получать одну и ту же последовательность случайных коэффициентов.

Результаты выводятся в терминал и сохраняются в файл:

```text
results.csv
```

Формат файла:

```text
n,degree,karatsuba_ms,toom3_ms
```

### `plot_results.py`

Python-скрипт для визуализации результатов эксперимента.

Скрипт читает `results.csv` и строит два графика.

Первый показывает измеренное время работы:

```text
Карацуба
Тоом — Кук-3
```

и сохраняется в:

```text
results_plot.png
```

Второй показывает теоретический рост сложности:

```text
Обычный алгоритм: O(n²)
Карацуба:         O(n^log₂3)
Тоом — Кук-3:     O(n^log₃5)
```

и сохраняется в:

```text
complexity_plot.png
```

## Запуск

### Требования

Для основной части лабораторной работы необходим:

```text
Go
```

Для построения графиков дополнительно необходимы:

```text
Python 3
matplotlib
```

При отсутствии `matplotlib` его можно установить командой:

```bash
python3 -m pip install matplotlib
```

## Проверка корректности

Перед проведением измерений рекомендуется запустить тесты:

```bash
go test
```

или с подробным выводом:

```bash
go test -v
```

Все реализации должны пройти одинаковый набор тестов.

## Проведение измерений

Если проект содержит `go.mod`, программу можно запустить из корневого каталога:

```bash
go run .
```

В противном случае можно явно передать исходные файлы:

```bash
go run main.go polynomial.go naive.go karatsuba.go toom3.go random.go benchmark.go
```

Программа последовательно выполнит измерения для `n` от `5` до `18`.

В терминале появятся результаты примерно следующего вида:

```text
n=5 degree=32 karatsuba=...ms toom3=...ms
n=6 degree=64 karatsuba=...ms toom3=...ms
...
n=18 degree=262144 karatsuba=...ms toom3=...ms
```

Одновременно будет создан файл:

```text
results.csv
```

## Построение графиков

После получения `results.csv` необходимо выполнить:

```bash
python3 plot_results.py
```

В результате будут созданы:

```text
results_plot.png
complexity_plot.png
```

Первый файл содержит экспериментальные результаты, второй — сравнение теоретического роста сложности алгоритмов.
